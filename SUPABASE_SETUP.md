# Campally Supabase Database Setup & Schema Guide

This document explains the database structure for **Campally** and outlines how new features safely integrate with your Supabase backend.

---

## 🛡️ Zero-Breakage Design Guarantee

The Campally codebase has been engineered with **automatic resilient fallbacks**:
* All new features (**Open to Swap / Trade**, **Course Codes**, **Preferred Safe Meetup Spots**, and **Student Requests Board**) are **100% functional immediately**.
* If the optional columns or tables below are not present in your Supabase project, Campally automatically embeds metadata safely into the existing schema (e.g. `[SWAP]`, `[Course: MTH101]`, `[Meetup: SUB]` in the description) and caches requests.
* **No queries or inserts will fail or crash.**

---

## 🚀 Optional Supabase SQL Enhancement Script

If you would like native database columns for these features in your Supabase project, simply open your **Supabase Dashboard** &rarr; **SQL Editor** &rarr; **New Query**, paste the script below, and click **Run**:

```sql
-- 1. Optional Campuses table for multi-campus support
CREATE TABLE IF NOT EXISTS campuses (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  name TEXT NOT NULL,
  active BOOLEAN DEFAULT true
);

-- 2. Add optional columns to the existing listings and profiles tables
ALTER TABLE listings 
  ADD COLUMN IF NOT EXISTS campus_id BIGINT REFERENCES campuses(id),
  ADD COLUMN IF NOT EXISTS is_swap BOOLEAN DEFAULT false,
  ADD COLUMN IF NOT EXISTS course_code TEXT DEFAULT NULL,
  ADD COLUMN IF NOT EXISTS safe_meetup_spot TEXT DEFAULT NULL;

ALTER TABLE profiles
  ADD COLUMN IF NOT EXISTS campus_id BIGINT REFERENCES campuses(id);

-- 3. Optional Student Requests (Wanted) Board table
CREATE TABLE IF NOT EXISTS requests (
  id TEXT PRIMARY KEY,
  title TEXT NOT NULL,
  course_code TEXT,
  hall TEXT,
  budget NUMERIC,
  details TEXT,
  whatsapp_number TEXT NOT NULL,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- 3. Enable Public Read & Insert Access for Requests (RLS)
ALTER TABLE requests ENABLE ROW LEVEL SECURITY;

CREATE POLICY "Allow public read on requests" 
  ON requests FOR SELECT 
  TO public 
  USING (true);

CREATE POLICY "Allow public insert on requests" 
  ON requests FOR INSERT 
  TO public 
  WITH CHECK (true);
```

## 📋 Schema Overview

### 1. `listings` Table
* `id` (bigint / uuid, primary key)
* `title` (text)
* `category_id` (foreign key to `categories.id`)
* `description` (text)
* `price` (numeric, null if free / negotiable / swap)
* `seller_id` (foreign key to `profiles.id`)
* `image_url` (text, public Supabase Storage URL)
* `status` (text, e.g. `'active'`)
* `is_swap` (boolean, *optional*)
* `course_code` (text, *optional*)
* `safe_meetup_spot` (text, *optional*)

### 2. `profiles` Table
* `id` (uuid, primary key, references `auth.users`)
* `full_name` (text)
* `department` (text)
* `hall` (text)
* `whatsapp_number` (text)
* `avatar_url` (text, public URL in `avatars` bucket)

### 3. `categories` Table
* `id` (bigint / uuid, primary key)
* `name` (text, e.g. `'Academic'`, `'Electronics'`, `'Services'`, `'Fashion'`)
* `slug` (text, e.g. `'academic'`, `'electronics'`, `'services'`, `'fashion'`)

### 4. `follows` Table
* `id` (uuid / bigint, primary key)
* `follower_id` (uuid, references `profiles.id`)
* `following_id` (uuid, references `profiles.id`)

### 5. `reviews` Table
* `id` (uuid / bigint, primary key)
* `reviewer_id` (uuid, references `profiles.id`)
* `seller_id` (uuid, references `profiles.id`)
* `rating` (integer, 1-5)
* `comment` (text)
* `created_at` (timestamptz)

### 6. `site_feedback` Table
* `id` (uuid / bigint, primary key)
* `name` (text, optional)
* `message` (text)
* `created_at` (timestamptz)

## 💳 Optional Paystack Monetization & Promotions SQL Schema

All Paystack features work instantly out of the box with server-side validation and persistent zero-breakage storage. If you would like native Supabase tables for transaction auditing, you can run:

```sql
-- Optional Transactions & Promotions tables
CREATE TABLE IF NOT EXISTS paystack_transactions (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  reference TEXT UNIQUE NOT NULL,
  plan_id TEXT NOT NULL,
  amount_kobo BIGINT NOT NULL,
  price_naira NUMERIC NOT NULL,
  customer_email TEXT,
  item_id BIGINT,
  user_id UUID REFERENCES auth.users(id),
  channel TEXT,
  paid_at TIMESTAMPTZ DEFAULT NOW()
);

CREATE TABLE IF NOT EXISTS campus_businesses (
  id TEXT PRIMARY KEY,
  name TEXT NOT NULL,
  category TEXT NOT NULL,
  campus_id BIGINT REFERENCES campuses(id),
  whatsapp TEXT NOT NULL,
  lodge TEXT,
  description TEXT,
  image_url TEXT,
  active BOOLEAN DEFAULT true,
  reference TEXT,
  created_at TIMESTAMPTZ DEFAULT NOW(),
  expires_at TIMESTAMPTZ
);

ALTER TABLE listings
  ADD COLUMN IF NOT EXISTS is_boosted BOOLEAN DEFAULT false,
  ADD COLUMN IF NOT EXISTS is_urgent BOOLEAN DEFAULT false,
  ADD COLUMN IF NOT EXISTS boost_expires_at TIMESTAMPTZ;

ALTER TABLE profiles
  ADD COLUMN IF NOT EXISTS is_pro BOOLEAN DEFAULT false,
  ADD COLUMN IF NOT EXISTS pro_expires_at TIMESTAMPTZ;
```
